# 💬 ChatFlow — Chat Colaborativo en Tiempo Real

Sistema de chat colaborativo en tiempo real usando WebSocket.

## 🚀 Tecnologías

- **Node.js** — servidor
- **ws** — librería WebSocket
- **HTML + CSS + JavaScript** — cliente web (sin frameworks)

## ✨ Funcionalidades

- Conexión de múltiples usuarios en simultáneo
- Asignación automática de nombre (Usuario_1, Usuario_2...)
- Posibilidad de cambiar el nombre
- Notificación cuando alguien entra o sale
- Historial de los últimos 50 mensajes
- Selector de emojis 😊
- Interfaz moderna oscura

## ⚙️ Instalación

### 1. Clona el repositorio

```bash
git clone https://github.com/miguelangelno/chat-websocket.git
cd chat-websocket
```

### 2. Instala las dependencias

```bash
npm install
```

### 3. Inicia el servidor

```bash
node server.js
```

### 4. Abre el chat

Abre el navegador en: **http://localhost:3000**

Para probar con varios usuarios, abre varias pestañas en la misma URL.
